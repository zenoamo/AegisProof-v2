# AegisProof v2.0.0 Release Notes

**Release date:** 2026-08-08  
**Tag:** `v2.0.0`  
**Commit:** see `git rev-parse v2.0.0` at release time  
**License:** MIT

## Summary

First public GitHub release of AegisProof v2 for external reviewers, researchers, and OSS contributors. This release publishes hash-pinned Groth16 artifacts, reproducibility CI, artifact provenance tooling, and security gates. **No mainnet deployment has been performed.**

---

## What's Included

### Frozen Groth16 Core (immutable)

- Circom circuit artifacts and R1CS references
- Production trusted setup hash pins:
  - `production.zkey`: `ce5a3d308868f2fe7a6a8e3b68d717c3217f84b0ddfbb3dc155338b9be4d6571`
  - VK ceremony hash: `d012bd29ff6e4c44b4c656c7af6b289c5c8286a1554ce7b2b8fd1a7d3c67d2ec`
- `publicSignals` layout: **30 signals**
- `Groth16VerifierV2Production.sol`, SDK (`packages/sdk/`), protocol contracts
- T1–T9 prover compatibility regression contract

### Additive Governance Layers (Phase 8.13–8.14)

- Artifact provenance manifest (`artifacts/provenance/manifest.json`)
- ML-DSA-87 PQC adapter (metadata signing — does not replace Groth16)
- Hybrid auth envelope (research layer)
- Repository security boundary scanner
- Penetration test suite (PT-01–PT-10)
- KMS signer abstraction (Phase 8.14 Task 2 — mock/stub backends)

### Documentation and Governance

- Architecture and security boundary docs
- ADRs 0001–0004 (frozen core, provenance, PQC, storage)
- MIT LICENSE, CONTRIBUTING.md, CODE_OF_CONDUCT.md
- Issue/PR templates with frozen-core checklist
- Public release audit report

## Known Limitations

1. **Migration debt:** 8 git-tracked binary paths (`production.zkey`, ptau, wtns) are allowlisted pending external secure storage migration.
2. **PQC on PR tier:** Manifest entries may be unsigned (WARN); strict `--pqc` runs on schedule/manual CI only.
3. **KMS production signing:** Design and stub complete; live Vault/HSM wiring is Phase 8.14 Task 3+.
4. **Hybrid auth:** Research layer only; not connected to deployment scripts.
5. **TEE:** ADR-001 isolated research; not part of production Groth16 path.

---

## Security

- Run `npm run check:sensitive-files` before contributing — never commit private keys or `.env` files.
- Report security issues via the [Security issue template](../../.github/ISSUE_TEMPLATE/security_report.yml).
- See [docs/security/github-public-release-audit-report.md](../security/github-public-release-audit-report.md).

---

## Upgrade / Compatibility

- This is the initial v2 public release. v1 artifacts are not compatible.
- Groth16 proofs generated with pinned `production.zkey` remain valid across patch releases when hash pins unchanged.
