# AegisProof 30秒紹介

## スクリプト（約30秒）

「情報を公開せずに、正しいことだけを証明する」
それがAegisProofです。

例えば、年齢確認で生年月日を全部見せる必要はありません。
「18歳以上であること」だけ証明できればいいのです。

医療データ、金融サービス、AIの信頼性確認。
個人情報を守りながら、必要な確認だけを行う。

プライバシーと透明性を両立した、
新しいセキュリティ基盤です。

## ポイント
