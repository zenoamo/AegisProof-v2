# Local Verifier Example

**Purpose:** Demonstrates offline proof verification using production VK without network access.

## Usage

```bash
cd examples/local-verifier
node verify.js
```

## Requirements

- `artifacts/phase4/final/production-vkey.json` — generated by Phase 4 ceremony
- `artifacts/phase4/reports/production_proof_baseline.json` — generated by `scripts/phase4_verify_production.mjs`

If these files are missing, run:

```bash
node scripts/phase4_verify_production.mjs
```

## What This Does

1. Loads production VK from disk
2. Verifies IC count equals 31 (Groth16)
3. Loads baseline proof artifact
4. Performs off-chain Groth16 verification using snarkjs
5. Reports public signal values (read-only inspection)

## What This Does NOT Do

- ❌ No network calls (fully offline-capable)
- ❌ No deployments
- ❌ No secret key exposure
- ❌ No state modifications

This is a pure read-and-verify operation.
